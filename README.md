# Bulletin Board — версия для Minecraft Forge

Forge-порт мода **Bulletin Board** для Minecraft **1.20.1**.
Функционал полностью повторяет Fabric-версию; изменено только ядро загрузчика (Forge вместо Fabric).

## Требования

| Компонент | Версия |
|---|---|
| Minecraft | 1.20.1 |
| Forge | 47.x (проверено на 47.2.0) |
| Java | 17+ |

## Сборка

```bash
./gradlew build
```

Готовый мод появится в `build/libs/bulletin-board-forge-1.3.jar`.

Запуск клиента/сервера для отладки:

```bash
./gradlew runClient
./gradlew runServer
```

## Что перенесено

- **Блоки:** доска объявлений (`bulletin_board`) и размещённая записка (`placed_note`) с
  собственными block entity, тиками и синхронизацией по сети.
- **Предметы:** бумага для записок (обычная и малая) и 17 цветных значков.
- **Слоты доски:** 5 позиций (4 малых + 1 большой), подсветка подходящих слотов в мире,
  автоматическое истечение записок через 1 час игрового времени (кроме записок с печатью).
- **GUI:** редактор записки, просмотр записки, кастомные виджеты (скруглённые кнопки и поля,
  переключатель).
- **Сеть:** 6 типов пакетов (взять записку, обновить NBT, взять размещённую записку,
  открыть записку, открыть размещённую записку, синхронизация имён жителей).
- **Деревни:** имена и профессии жителей над головой, синхронизация имён между игроками,
  сохранение в данных мира, деревенские скидки при событиях.
- **Команды:** `/bulletin trigger`, `/bulletin trigger-at`, `/bulletin list`, `/bulletin clear`,
  `/bulletin info` и др.
- **Генерация:** внедрение доски в пулы деревенских домов (5 биомов).
- **Конфиги:** `config/bulletin-board/config.json5` (JSON5 с комментариями),
  `config/bulletin-board/notes/*.json`, `config/bulletin-board/villager_names.json`.
- **Интеграция:** опциональная поддержка мода Trade Overhaul (через рефлексию, без жёсткой зависимости).

## Отличия от Fabric-версии

Идентификатор мода для Forge — `bulletin_board` (Forge не допускает дефис в modId),
при этом namespace ресурсов остался прежним — `bulletin-board`, поэтому все ассеты, рецепты
и данные сохранены без изменений и совместимы с существующими ресурспаками.

Технические детали портирования (соответствия Yarn → Mojang mappings, замена Fabric API,
реализация инъекции структур) описаны в [PORTING-NOTES.md](PORTING-NOTES.md).
